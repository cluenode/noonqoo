기기 데이터외부 서비스삭제 방법문의

1. 적용 범위와 운영자

Noonqoo는 더쿠의 공개 모바일 웹을 읽고 사용자의 읽음 기록·키워드 규칙·미디어 보관함을 기기에서 관리하는 비공식 앱이다. 더쿠 또는 운영사의 공식 앱이나 제휴 서비스가 아니다. 이 방침은 Noonqoo Android 및 iOS 앱(io.noonqoo.companion)에 적용된다. 개인정보 처리 및 앱 운영 문의 담당은 cluenode이며 연락처는 cluenode@gmail.com이다.

2. 기기에 저장하는 정보와 이용 목적

  • 읽음 상태·최근 읽은 글·탐색 위치: 읽던 흐름 복원과 새 댓글 표시.
  • 게시판 즐겨찾기·그룹·키워드 규칙·설정: 개인별 탐색과 화면 구성.
  • 직접 저장한 이미지·영상과 영상 미리보기, 외부 미디어·웹 링크 주소와 제목·저장 시 생성한 로컬 썸네일과 저장 당시 원문 글 번호·게시판·제목, 폴더·태그·메모·좋아요: 보관함 감상과 정리.
  • 지켜보는 글·댓글 확인 기준·시도 시각·알림 처리 기록: 새 댓글 변화 확인과 중복 알림 방지.
  • 웹 쿠키·캐시·사이트 데이터: 플랫폼 웹 컨테이너의 웹페이지 표시.

앱 계정, 자체 동기화 서버, 앱에 포함한 분석·광고·오류 수집 SDK는 없다. 위 앱 데이터는 앱 전용 저장소에서 관리하며 운영체제 클라우드 백업 대상에서 제외한다. 앱은 이 로컬 기록을 개발자 서버로 업로드하지 않는다. 외부 웹 통신은 아래와 같이 별도로 발생한다.

3. 웹 탐색과 외부 서비스로 전송되는 정보

공개 글·게시판을 열면 더쿠와 해당 페이지가 포함한 광고·이미지·영상·임베드 서비스로 요청이 전송된다. 해당 서비스는 연결 과정에서 IP 주소, 요청 경로·시각과 웹 컨테이너가 전송하는 정보를 처리할 수 있다. 웹 콘텐츠의 쿠키·식별자 처리와 보유 기간은 해당 서비스 정책에 따른다. Noonqoo가 제3자 웹서비스의 보유·삭제 방식을 통제하지는 않는다. 원문 웹페이지의 광고는 그대로 표시되며, Noonqoo 자체 광고 SDK는 포함하지 않는다.

더쿠의 공개 개인정보처리방침은 IP·쿠키·기기/브라우저 정보·서비스 이용기록 수집과 접속 로그 등의 3개월 보관을 안내합니다. 자세한 범위는 더쿠 개인정보처리방침을 따릅니다.

Android의 ‘연속 읽기 미리 준비’는 기본적으로 Wi-Fi에서 현재 목록의 검증된 다음 글 한 개와 이전 글 한 개 이하를 미리 준비할 수 있다. 실제 이동 전에 페이지와 하위 자원 요청이 발생할 수 있다. ‘항상’은 모바일 데이터에서도 허용하고, ‘사용 안 함’은 이 준비 요청을 중지한다.

게시판 목록 갱신, 사용자가 요청한 본문 이미지 보기·미디어 저장과 지켜보는 글 확인도 해당 공개 서버에 요청을 보낸다. 게시판 목록·직접 파일 저장·지켜보기의 별도 요청은 쿠키·리퍼러 등 자격 증명을 전달하지 않도록 제한한다. 원문·외부 플레이어의 웹 요청에는 플랫폼 웹 데이터 정책이 적용된다. 지켜보기는 사용자가 자동 확인을 켰거나 수동 확인을 요청할 때 동작하며 운영체제 상태에 따라 지연될 수 있다.

외부 링크를 저장할 때 해당 서비스의 임베드 또는 공개 이미지, 웹 페이지의 제목·대표 이미지를 요청해 로컬 미리보기를 만든다. 보관함에서 외부 미디어를 열면 해당 서비스의 전용 웹 플레이어로 요청·재생하며 서비스 자체의 콘텐츠·쿠키 정책이 적용될 수 있다.

사용자가 공유·내보내기를 선택하면 선택한 파일 또는 외부 링크 주소가 사용자가 지정한 앱 또는 저장 위치로 전달된다. 이후 사본은 해당 앱·저장 서비스의 설정과 정책에 따라 처리된다.

4. 보관·삭제와 선택권

로컬 기록은 사용자가 기능별로 삭제하거나 앱 데이터를 삭제할 때까지 보관됩니다. Android에서는 앱 설정의 ‘모든 로컬 데이터 삭제’로 예약 작업과 알림을 정리하고 웹 데이터를 포함한 앱 데이터를 삭제할 수 있습니다. Android 시스템 설정의 앱 데이터 삭제 또는 앱 제거도 가능합니다. iOS에서는 기능별 삭제 또는 iOS의 ‘앱 삭제’를 사용합니다. ‘앱 정리하기’는 로컬 데이터를 남길 수 있으므로 전체 삭제가 필요하면 ‘앱 삭제’를 선택합니다. 공유·내보내기로 별도로 만든 사본은 해당 저장 위치에서 따로 삭제해야 합니다.

알림 권한을 거부해도 앱을 사용할 수 있다. 자동 확인과 미리 준비는 앱 설정에서 조절할 수 있다. 앱은 계정 생성·로그인 기능을 제공하지 않아 Noonqoo 계정 삭제 절차는 없다.

5. 권한과 보호 조치

  • 인터넷·네트워크 상태: 공개 웹페이지와 미디어 요청, 미리 준비의 네트워크 조건 확인.
  • 알림: 사용자가 허용한 지켜보는 글의 댓글 변화 안내. 알림 권한은 거부하거나 철회할 수 있다.

앱은 위치·연락처·카메라·마이크·전화·문자 또는 전체 저장소 접근 권한을 요청하지 않는다. 공유와 내보내기는 Android 및 iOS 시스템 선택 화면을 통해 사용자가 대상을 정한다.

앱의 지원 웹 주소와 직접 네트워크 요청은 HTTPS로 제한하며, 앱 전용 저장소와 플랫폼 권한을 사용한다. 데이터를 공유·내보내는 경우 사용자가 선택한 수신 앱의 보호 조치는 별도로 적용된다.

6. 이메일 문의와 삭제 요청

문의처: cluenode@gmail.com. 사용자가 이메일을 보내면 발신 이메일 주소, 문의 내용과 직접 첨부한 자료를 문의 답변과 문제 해결에 이용한다. 문의에 필요하지 않은 비밀번호·인증 코드·민감한 정보는 보내지 않아야 한다. 이메일은 Google의 이메일 서비스를 통해 처리되며 해당 서비스의 정책도 적용된다.

문의 정보는 문의 해결 후 30일 이내 삭제한다. 법령상 보관 의무가 적용되거나 진행 중인 분쟁의 대응에 필요한 경우에는 그 사유에 필요한 범위와 기간에 한해 보관한 뒤 삭제한다. 문의 정보의 열람·정정·삭제 요청은 같은 주소로 보낼 수 있다. 기기의 로컬 기록은 운영자가 원격으로 열람하거나 삭제할 수 없으므로 위 기능별 삭제 또는 앱 데이터 삭제 방법을 이용한다.

7. 방침 변경

앱 기능이나 데이터 처리 방식이 바뀌면 이 페이지의 시행일과 변경 내용을 갱신한다. 중요한 변경은 앱 또는 배포 페이지를 통해 안내한다.
